# Security and publication scope

This repository is a **public, documentation-only portfolio case study**. It intentionally excludes production source code, live demos, images, private Git history, customer data, and confidential deployment details.

## Content policy
- Do not commit secrets, tokens, environment files, private keys, webhook secrets, API credentials, or configuration containing real identifiers.
- Do not commit real leads, contact lists, call recordings or transcripts, customer details, proprietary company documents, or service agreements.
- Do not copy code or full documentation wholesale from the private source without a separate security and rights review.
- Any future examples must be fictional and labeled as examples.
- Review any future changes for privacy, licensing, accuracy, and intellectual-property obligations before publishing.

## Claims
The repository describes design decisions and functionality documented in the original project. It is **not** proof of a deployed service, audited business ROI, or independently verified performance.

## Contact
For questions about this portfolio, use the repository's GitHub Issues or the owner's [GitHub profile](https://github.com/3104david-sketch). Do not post credentials or customer data in an issue.
